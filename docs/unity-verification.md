## 尚未执行

当前环境没有 Unity Editor 和已配置的许可，以下项目均为 **待验证**，没有 Unity 截图、实测性能或 Unity APK 产物：

1. 用目标 Unity 6000.0.60f1 导入工程，确认 Console 无错误，打开场景并 Play。
2. 检查 9:16、9:19.5、刘海屏安全区；所有数字及中文应可读，无粉色材质、遮挡或裁切；窗口改变尺寸时棋盘触摸位置仍准确。
3. 经典模式分别完成 3×3、4×4、5×5；正确/错误/重复点按符合规则，暂停期间完全看不到数字。
4. 验证 3→2→1 倒计时期间不能点按；此时切后台应取消倒计时，返回后从准备状态重新开始。
5. 限时模式分别验证胜利、20/35/60 秒超时、最后一刻点按、后台暂停；误触不额外扣时。
6. 连击在 1.6 秒以内递增，误触或暂停后从 1 开始；声音、光波与粒子跟随正确点按。
7. 进行中切模式或尺寸出现确认；取消应保留棋盘，确认开始新局且不影响最佳纪录。
8. 进行中 Home、锁屏、来电或丢失焦点：停表并存进度；回来后手动继续。暂停后重启进程应恢复同一棋盘、用时和误触数。
9. 完成一局后重启：分模式/尺寸的最佳成绩和设置持久化；超时不写入最佳成绩，损坏的未完成进度安全丢弃。
10. 音效/触感关闭后不再触发；系统关闭触感时遵循系统设置；减少动态效果时不再产生粒子和位移动画。
11. 生成 ARM64 APK，检查包名、版本、安装/启动；在低端与主流真机测帧率、启动耗时、内存、发热和包体大小。60 fps 只是目标，并非实测结论。
12. 单独验证覆盖升级：相同包名和签名下从原生 v1 升级，检查成绩、设置及未完成棋盘迁移。默认并存包不做跨沙箱迁移。

第一版使用 Unity 画布和三维棋盘；与原生 Android 控件相比，TalkBack 语义支持仍需后续补齐。本版提供较大触点、音效/触感开关与减少动态效果，但不声称已满足完整无障碍要求。
